# Kamerdent — демо-сайт стоматологии

Статический сайт без сборки: HTML + CSS + ES-модули. Все данные клиники — в `js/config.js`.

## Запуск локально

ES-модули не работают при открытии через `file://`, поэтому нужен локальный сервер:

```
npx serve .
```

и открыть http://localhost:3000 (порт может отличаться).

## Под новую клинику

1. `js/config.js` — название, телефон, WhatsApp, адрес, часы, врачи, тексты (TR / EN / AR). Всё, что помечено `// ЗАМЕНИТЬ`, проверить у клиники.
2. `img/` — заменить фотографии:
   - `hero.webp` — главный экран (вертикальное фото 4:5, лучше без лиц и текста);
   - `why.webp` — блок «Почему мы» (горизонтальное 4:3);
   - `doc1–3.webp` — портреты врачей (4:5);
   - `g1–g8.webp` — галерея клиники (любые пропорции, вёрстка masonry);
   - `og.jpg` — превью для соцсетей, 1200×630;
   - `favicon.svg` / `apple-touch-icon.png` — иконки.
   При замене обнови `width`/`height` у галереи в `config.js` (нужны, чтобы не прыгала вёрстка).
3. Цвета и шрифты — переменные в начале `css/style.css` (`--bg`, `--primary`, `--sand`, `--fh`, `--fb`).
4. Поменять `https://kamerdent.com/` на реальный домен в `index.html` (canonical, og, twitter), `sitemap.xml` и `robots.txt`.
5. Перед продакшеном: `isDemo: false` в `config.js` (снимает `noindex`).
6. В футере поля «Sorumlu Müdür» и «Ruhsat No» скрываются, пока не заполнены (в демо стоят прочерки). Для реального сайта их нужно заполнить — это требование турецкого регулирования.

## Фото

Сейчас стоят стоковые фотографии с Unsplash (свободная коммерческая лицензия) — это заглушки. Перед запуском клиника должна прислать реальные фото клиники и врачей. Нельзя использовать фото пациентов, отзывы, рейтинги, фото «до/после», цены и скидки — это запрещено турецким регламентом о рекламе медицинских услуг (Sağlık Hizmetlerinde Tanıtım ve Bilgilendirme Faaliyetleri Hakkında Yönetmelik, Resmî Gazete 12.11.2025, sayı 33075).

## Деплой на Vercel

`npx vercel` в папке проекта, или залить в GitHub → Import в vercel.com. Сборка не нужна.

## Безопасность (`vercel.json`)

CSP без inline-скриптов (JSON-LD — не исполняемый скрипт), HSTS, X-Frame-Options DENY, nosniff, Referrer-Policy, Permissions-Policy.
Данные формы не отправляются на сервер — только через WhatsApp пользователя (нет бэкенда, нет хранения персональных данных). Весь вывод через `textContent`, без `innerHTML`.

## SEO

- `title` / `description` / Open Graph / Twitter — в `index.html` (TR) и в `config.js` (для EN/AR);
- микроразметка `Dentist` и `FAQPage` (JSON-LD) генерируется в `js/main.js`;
- `robots.txt` и `sitemap.xml` в корне;
- демо закрыто от индексации через `isDemo: true`.
